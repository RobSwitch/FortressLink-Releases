# Fortress Link — versions de test

**Fortress Link** est un jeu PvP 3v3 qui mélange MOBA et tower defense : défends ton château,
envoie tes vagues d'unités sur 3 lanes, capture les avant-postes et écrase le château adverse.

## Installer le jeu (testeurs)

1. **Télécharge le launcher** :
   [FortressLinkLauncher.zip](https://github.com/RobSwitch/FortressLink-Releases/releases/download/launcher-v1.0.0/FortressLinkLauncher.zip)
2. **Décompresse** le fichier où tu veux (par exemple sur ton Bureau).
3. **Lance `FortressLinkLauncher.exe`**.
   Windows peut afficher « Windows a protégé votre ordinateur » (le jeu n'est pas signé) :
   clique sur **Informations complémentaires**, puis **Exécuter quand même**.
4. Clique sur **INSTALLER**, puis sur **JOUER**.

Le launcher vérifie les mises à jour à chaque lancement : quand une nouvelle version sort,
clique simplement sur **METTRE À JOUR**. Utilise toujours le launcher pour lancer le jeu.

Le jeu est installé dans `%APPDATA%\FortressLink\game` (pour le désinstaller, supprime ce dossier
et le launcher).

## Configuration

- Windows 10 ou 11, 64 bits.
- Une carte graphique récente (le jeu utilise Vulkan / DirectX 12).

## Les versions

Toutes les versions et leurs notes sont dans l'onglet
[Releases](https://github.com/RobSwitch/FortressLink-Releases/releases).
Le numéro de version est affiché en haut de l'écran dans le jeu : indique-le quand tu fais un retour.
